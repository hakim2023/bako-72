# Bako-72 Restaurant

Site du restaurant Bako-72 : cuisine africaine traditionnelle faite maison, Saint-Denis.

- `index.html` : site (carte interactive, commande, infos pratiques, plan)
- `menu.html` : carte A4 prête à imprimer, avec QR code vers le site
- `data.js` : la carte (plats, prix) — modifier ici, les deux pages se mettent à jour
- `bako-72-menu.pdf` : la carte en PDF

Site statique hébergé gratuitement sur GitHub Pages. Réalisé par [Fix & Web](https://hakim2023.github.io/).
